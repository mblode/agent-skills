# Ticket Reply

## Steps

1. Read the whole ticket thread, oldest message first. Find what the customer is actually blocked on; it is often not the first thing they asked.
2. Answer that in the first sentence.
3. Give the steps as a numbered list only when there are three or more.
4. Close with what happens next and who does it.

## Gotchas

- Never promise a date for an unreleased feature. Say it is planned and offer to add them to the notify list.
- A refund request over 200 pounds is escalated to a team lead, not answered.

# Branching

- Branch from `main`. Name the branch `<ticket>-<two-or-three-words>`, for example `LAR-482-snooze-recurring`.
- One ticket per branch. A follow-up ticket gets its own branch off the first one if it depends on it.
- Commit subjects are imperative and start with the ticket key: `LAR-482 Add snooze to recurring tasks`.
- Do not rebase a branch after someone has reviewed it. Merge `main` in instead.

## Read aloud, cut redundancies, check logic gaps

Read the doc aloud -- if you stumble, readers will too. Check that every step logically follows the previous one. Cut any sentence that does not earn its place. Aim to remove 20% of the words on each editing pass.

**Incorrect (first draft published without editing):**

```markdown
In order to be able to configure the application, you will
need to first make sure that you have created a configuration
file. This configuration file should be created in the root
directory of the project.
```

**Correct (edited to remove filler and redundancy):**

```markdown
Create a configuration file in the project root directory.
```

Reference: [Google developer documentation — Writing style](https://developers.google.com/style)

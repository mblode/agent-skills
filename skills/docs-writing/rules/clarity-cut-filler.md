## Cut filler words and throat-clearing phrases

Remove "very," "really," "just," "basically," "actually," "quite," and "simply" -- they add length without meaning. Also cut "in order to" (use "to"), "it is important to note that" (delete entirely), and "as mentioned above" (link instead).

**Incorrect (filler words dilute the instruction):**

```markdown
It is important to note that you should basically just configure
the very simple settings. In order to actually get started, you
really need to simply install the dependencies.
```

**Correct (every word earns its place):**

```markdown
Configure the settings. To get started, install the dependencies.
```

Reference: [Google Technical Writing — Short sentences](https://developers.google.com/tech-writing/one/short-sentences)

## Standard US English, no idioms or cultural references

Many readers are non-native English speakers or use automated translation. Write in standard US English. Avoid idioms ("out of the box"), sports metaphors ("home run"), and cultural references.

**Incorrect (idioms and metaphors don't translate):**

```markdown
This feature works out of the box and is a real game-changer.
Once you get the hang of it, you'll hit the ground running.
```

**Correct (literal language translates cleanly):**

```markdown
This feature works without additional configuration and
significantly improves performance. After the initial setup,
you can start using all endpoints immediately.
```

Reference: [Google Developer Documentation Style Guide — Writing for a global audience](https://developers.google.com/style/translation)

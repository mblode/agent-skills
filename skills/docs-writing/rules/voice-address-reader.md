## Address the reader as you

Address the reader directly as "you." Second person creates an immediate connection and makes instructions unambiguous. Third-person phrases like "the user" or "developers" create distance and raise the question: is the reader the user, or someone else? "One" sounds academic and stiff.

Reserve "the user" for situations where you're writing about a different person than the reader, such as when the reader is building something for their own users.

**Incorrect (third-person reference to the reader):**

```markdown
The user can configure the database connection by editing the settings
file. Developers should ensure that the credentials are stored securely.
One must restart the service after making changes.
```

**Correct (direct second-person address):**

```markdown
You can configure the database connection by editing the settings file.
Make sure you store your credentials securely. Restart the service after
making changes.
```

Reference: [Google developer documentation style guide — Second person](https://developers.google.com/style/person)

## Put the most important information first

Readers decide within seconds whether a section is relevant. Lead sentences with key information. Lead sections with the main point. Push caveats, edge cases, and alternatives to the end.

**Incorrect (buries the recommendation after qualifications):**

```markdown
While there are several approaches, and depending on your use
case, you might want to consider the trade-offs between
performance and simplicity. After evaluating the options, the
recommended approach is to use connection pooling.
```

**Correct (leads with the answer, then provides context):**

```markdown
Use connection pooling. For alternative approaches, see
[Alternatives](#alternatives).
```

Reference: [Nielsen Norman Group — Inverted pyramid](https://www.nngroup.com/articles/inverted-pyramid/)

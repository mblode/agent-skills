## Replace vague claims with specific details

Vague words like "fast," "easy," "flexible," and "powerful" mean nothing without specifics. Quantify or give a concrete example.

**Incorrect (vague adjectives provide no useful information):**

```markdown
The API is fast and handles many concurrent requests. Setup is
easy and the system is highly flexible.
```

**Correct (specific numbers let readers evaluate claims):**

```markdown
The API responds in under 50ms and handles 10,000 concurrent
requests. Setup takes under 5 minutes. The system supports
custom plugins, webhook endpoints, and configurable retry policies.
```

Reference: [Google Developer Documentation Style Guide — Word list](https://developers.google.com/style/word-list)

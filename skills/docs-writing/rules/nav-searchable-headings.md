## Write headings that match what readers search for

Use the words readers actually type when looking for this information. Include the feature name or action in the heading. Generic headings like "Common issues" or "More info" don't match any search query.

**Incorrect (generic headings):**

```markdown
## Common issues

## More information

## Overview
```

**Correct (specific, searchable headings):**

```markdown
## Troubleshoot authentication errors

## Configure rate limits

## Deploy to production
```

Reference: [Google developer documentation style guide — Headings](https://developers.google.com/style/headings)

## Test docs with a fresh reader who has no context

The author cannot objectively evaluate their own docs -- they know too much. Have someone unfamiliar with the feature follow the doc from scratch. Note where they get stuck or ask questions.

**Incorrect (self-review only):**

```markdown
## Review checklist

- [x] Author reviewed for typos
- [x] Author verified steps work
```

**Correct (fresh reader validates independently):**

```markdown
## Review checklist

- [x] Author reviewed for typos
- [x] Author verified steps work
- [x] Fresh reader followed the doc from scratch
- [x] Confusion points addressed: steps 3 and 7 rewritten
```

Reference: [Write the Docs — Documentation testing](https://www.writethedocs.org/guide/)

## Replace complex words with plain alternatives

Use "use" not "utilize," "help" not "facilitate," "start" not "initiate." Complex words signal insecurity, not expertise.

**Incorrect (inflated vocabulary obscures meaning):**

```markdown
Utilize the dashboard to facilitate the initialization of your
deployment. This functionality enables the administrator to
ascertain the current operational status.
```

**Correct (plain words communicate faster):**

```markdown
Use the dashboard to start your deployment. This lets the
admin check the current status.
```

Reference: [Federal Plain Language Guidelines](https://www.plainlanguage.gov/guidelines/words/use-simple-words-phrases/)

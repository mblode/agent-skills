## Headings must describe the section content

Readers scan headings before reading content. Each heading should tell the reader what they will learn in that section. Avoid generic headings like "Overview," "Details," or "More info" -- they force readers to read the body to determine relevance.

**Incorrect (generic headings that don't communicate content):**

```markdown
## Overview

## Details

## Additional information

## More info
```

**Correct (headings that tell the reader what to expect):**

```markdown
## Set up database connections

## Rate limit configuration

## Error codes and troubleshooting
```

Reference: [Google developer documentation — Headings and titles](https://developers.google.com/style/headings)

## Mix short and long sentences for rhythm

Uniform sentence length creates monotony. Alternate between short punchy sentences (5-10 words) and longer explanatory ones (15-25 words). Short sentences create emphasis and break up dense explanations.

**Incorrect (uniform short sentences that read like a list):**

```markdown
The system processes requests. The system validates input. The
system returns responses. The system logs errors.
```

**Correct (varied lengths that create natural rhythm):**

```markdown
The system processes each request in three stages. First, it
validates the input. Then it generates a response and returns it
to the client. Errors are logged automatically.
```

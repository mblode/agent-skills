Marlin Parcels API

Send your key in the X-API-Key header. Every request and response body is JSON.

Shipments

  • POST /shipments: create a shipment from a recipient, a weight in grams, and a service.
  • GET /shipments: list shipments, optionally filtered by status.
  • GET /shipments/{id}: fetch one shipment.
  • GET /shipments/{id}/events: list its tracking events.

Rates

  • POST /rates/quote: quote every service for a weight in grams.

Limits

Each key may make 120 requests a minute.

The machine-readable description is at /openapi.json.
